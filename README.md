💪 Fitness Tracker App

Fitness Tracker is a simple Android application built as a college project.
It helps users manage their fitness activities — track workouts, steps, and calories — with a clean and intuitive interface.

✨ Features

Log and edit workouts (exercise type, duration, calories burned)

Step count tracking (manually or via sensor)

View daily and weekly fitness summaries

Visual progress charts to monitor trends

Simple and modern UI design

Uses local storage (SQLite) — no online database required

Built with Kotlin and XML layouts

🛠️ Technologies Used

Language: Kotlin

Framework: Android SDK

IDE: Android Studio

UI Components: ConstraintLayout, RecyclerView, CardView, EditText, Button

Storage: SQLite
